What's new

Quire updates itself; this is the list of what each version brought. The current version is the latest, published recently. Download it.

Quire 0.3.0 2026-09-14

  • EPUB support: one long scrolling document like a PDF, zoom that magnifies without reflowing, Aa panel for font, size, line height and column width, right-to-left books and Arabic typography, table of contents, find in book, highlights anchored to the text
  • Read EPUBs on the phone with the same engine (pinch to zoom, dark mode, highlights)
  • Highlight from the phone remote: a cursor on the desktop that you move and drag with the phone to select text, then pick a colour and a note
  • Highlights list on the phone remote, tap to jump there on the desktop
  • Auto-updates: Quire downloads new versions in the background and installs them when you restart
  • About dialog with the privacy statement and a support link

Quire 0.2.0 2026-09-12

  • Library with watched folders, covers and online metadata
  • Highlights and notes, on the desktop and on the phone
  • Read on the phone (handoff) with pinch to zoom

Quire 0.1.0 2026-09-10

  • PDF reader with continuous scroll, zoom, find, dark mode and couch mode
  • Phone remote paired with a QR code
