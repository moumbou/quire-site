Privacy

Last updated 14 September 2026

Quire is a desktop application. It has no accounts, no analytics, no crash reporting and no advertising. This page lists every situation in which it talks to the network, so there are no surprises.

What stays on your computer

Your books are never modified or uploaded. Your library (the list of books and where they are), reading positions, highlights, notes and settings are stored in a single folder under your Windows user profile (%APPDATA%\com.nexaforgepixel.quire). Delete that folder and Quire forgets everything. Uninstalling removes the application; the data folder is left in place so you can reinstall without losing highlights, and you can delete it by hand.

When Quire connects to the internet

1. Book details (optional)

When a book is added to the library, Quire can look up its cover, author and description. It sends the book's ISBN, or its title and author when there is no ISBN, to Google Books and Open Library, and nothing else. This lookup can be switched off in the library settings, in which case Quire uses only what is inside the file.

2. Updates

Quire checks for a new version shortly after it starts and about every six hours while it runs, by fetching a small file from GitHub (github.com/moumbou/quire-releases). The request contains the usual information any download does (your IP address and a user agent naming Quire and its version); nothing about you or your books. If a new version exists it is downloaded in the background and installed when you restart. You can turn automatic downloads off in About Quire; checking is then done only when you ask for it. Every update is signed, and Quire refuses an update whose signature does not match.

The phone remote

The remote runs a small web server inside Quire, on your computer, only while the remote panel is open. Your phone connects to it over your local network; the connection never goes through the internet or any server of mine. Pairing requires scanning the QR code or typing the one-time code shown on the desktop, and a new code is generated each time the panel is opened. When a book is "handed over" to the phone, the file is served to the phone over that same local connection and is not stored on the phone.

What I can see

Nothing. There is no server on my side, so I do not know how many people use Quire, which books they read or whether an update succeeded. The only thing I receive is whatever you choose to write to me by email.

Third-party services

The three services above have their own policies: Google (Books API), Internet Archive (Open Library) and GitHub (downloads and updates). This website is hosted on GitHub Pages and uses no cookies or analytics; it makes one request to the GitHub API to display the current version number.
